Private-by-default web browser · Flatpak for any Linux distro

Install

Install Reyva

Opens in your software center (GNOME Software, KDE Discover). Or from a terminal:

flatpak install --user https://reypaulino.github.io/reyva-flatpak/com.reyapps.Reyva.flatpakref

Updates arrive with your normal Flatpak updates (software center, or flatpak update).

Already installed Reyva from a .flatpak file?

That copy doesn't update itself. Remove it once, then install from here (your settings stay in ~/.var/app/com.reyapps.Reyva/):

flatpak uninstall --user com.reyapps.Reyva
flatpak install --user https://reypaulino.github.io/reyva-flatpak/com.reyapps.Reyva.flatpakref
